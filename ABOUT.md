# About MODEL 01 LITE

MODEL 01 LITE is a free, English-only, photo wall-calendar generator written in Python. It produces a printable A4 PDF with a cover, twelve monthly photo calendars and a full-year overview. The project is intended as a simple, easy-to-test GitHub demonstration of a desktop calendar generator.

**Technology:** Python, Tkinter (desktop GUI), Pillow (images), ReportLab (PDF).

**Privacy:** No accounts, no uploads to servers, no network API calls. Your selected images are processed locally. Dependency installation requires internet access once.

**Output:** `output/` beside the Python script. Filenames include the year and a generation timestamp.

**Languages:** English only. **Calendar:** Gregorian only. This edition intentionally has no Arabic text or Hijri calendar support.
